# Google 広告 改善プラン（インプラント新患獲得）

たなか歯科クリニック（兵庫県たつの市龍野町）のインプラント相談予約を増やすための、Google 広告の修正内容と入稿データです。

| ファイル | 内容 |
| --- | --- |
| `keywords.csv` | 広告グループ別のキーワード（フレーズ一致中心） |
| `negative-keywords.csv` | 除外キーワード（求人・医療者向け・他分野・商圏外） |
| `responsive-search-ads.csv` | レスポンシブ検索広告の見出し15本・説明文4本・表示URLパス |
| `assets.csv` | サイトリンク・コールアウト・構造化スニペット・電話アセット |

見出し（全角15文字以内）・説明文（全角45文字以内）・サイトリンク等の文字数は、Google 広告の上限（全角=2文字換算）に収まることを確認済みです。

## 1. これまでの主な問題点と修正内容

| # | 問題点 | 影響 | 修正 |
| --- | --- | --- | --- |
| 1 | LP の見出しが「歯を失った方へ」で、インプラントの検索意図と一致していない | 品質スコア低下 → クリック単価上昇・直帰増 | ファーストビューを「たつの市でインプラントをご検討中の方へ」に変更し、広告文と言葉をそろえた |
| 2 | ボタンが「無料相談」なのに、注記では「保険適用内」（＝有料） | 景品表示法・医療広告ガイドライン上の不当表示リスク、広告審査の不承認リスク、来院時の不信感 | 「インプラント相談を予約する」に統一。除外キーワードに「無料」を追加 |
| 3 | 自由診療であるインプラントの**費用・期間・リスク**が LP に記載されていない | 医療広告ガイドラインの「限定解除」要件を満たさず、広告として掲載できない内容が含まれる状態 | 「治療の流れと費用」セクションを新設（**費用は医院で記入が必要**、下記参照） |
| 4 | コンバージョン計測が未設定 | 自動入札が機能せず、どのキーワードが予約につながったか分からない | 電話タップ・WEB予約クリックを計測するタグを実装（ID の差し替えが必要） |
| 5 | 高齢・持病・他院で断られた方など、当院の強みが活きる検索語が狙えていない | 価格比較の激戦キーワードに予算が集中 | 「悩み・不安」広告グループを新設 |

## 2. 配信開始前に医院で必ず行うこと

1. **LP の費用欄を記入する**（`index.html` の `TODO(医院確認)` の箇所）
   `〇〇〇,〇〇〇円` を実際の税込料金に差し替えてください。未記入のまま広告配信しないでください。
2. **コンバージョン ID の差し替え**（`index.html` 冒頭の `window.TANAKA_ADS`）
   - Google 広告 → 目標 → コンバージョン → 「ウェブサイト」で 2 つ作成
     - `WEB予約クリック`（カテゴリ：予約）
     - `電話タップ`（カテゴリ：電話での問い合わせ）
   - 発行された `AW-xxxxxxxxxx` と各ラベルを入力すると、計測タグが自動で有効になります
   - あわせて「広告の電話番号アセットからの通話（60秒以上）」もコンバージョンに設定してください
3. **表記内容の確認**
   - 「日本老年歯科医学会 専門医・指導医」は医療法上、広告可能な専門性資格に含まれるかを確認してください。含まれない場合は LP 上の表記を経歴の記載にとどめる必要があります（広告文には使用していません）
   - 治療期間・通院回数・リスクの記載内容が院の実態と合っているか確認してください
4. **Google ビジネスプロフィール**を広告アカウントにリンクし、住所アセットを有効にする

## 3. キャンペーン設定

| 項目 | 設定値 | 理由 |
| --- | --- | --- |
| キャンペーンタイプ | 検索のみ（ディスプレイ ネットワーク・検索パートナー：オフ） | 医療は意図の強い検索に集中させる |
| 地域 | 当院から半径 15km（たつの市・太子町・相生市・宍粟市・姫路市西部） | 来院可能な商圏に限定 |
| 地域ターゲティングの方法 | **「所在地：ターゲット地域に所在または定期的に訪れているユーザー」** | 初期設定の「関心」だと商圏外にも配信される |
| 言語 | 日本語 | |
| 入札戦略 | 開始〜CV 30件：「クリック数の最大化」（上限CPC 300円）→ CV 30件以降：「コンバージョン数の最大化」→ 安定後に目標CPA | 計測データが貯まるまでは自動入札が学習できない |
| 予算目安 | 1日 2,000〜3,000円（月 6〜9万円） | 地域 × インプラントの検索ボリュームに見合う規模 |
| 広告スケジュール | 毎日 6:00〜23:00。木曜午後・日曜は電話アセットを非表示 | 休診時間の電話は取りこぼしになる |
| デバイス | スマートフォン優先（入札調整 +20%）、診療時間中の電話表示 | 50〜70代もスマホ検索が主流 |
| 年齢 | 18〜24歳を −50%（除外はしない） | 本人以外に家族が検索するケースがあるため除外はしない |

### 広告グループ構成

1. **地域×インプラント**：「たつの市 インプラント」など。最重要。見出し1（固定）は「たつの市のインプラント相談」
2. **インプラント（地域絞込み）**：「インプラント 歯医者」など地域名なしの検索。地域ターゲティングで絞る
3. **悩み・不安（当院の強み）**：「高齢 インプラント」「糖尿病 インプラント」「インプラント 断られた」など。競合が少なく、老年歯科・全身管理の強みが最も伝わる
4. **指名**：「たなか歯科クリニック」など。競合に指名を奪われないため少額で配信

最終ページ URL は全グループ共通で LP トップ。サイトリンクで `#implant-info`（費用）、`#comparison`（比較）、`#faq` に誘導します。

## 4. 医療広告ガイドライン・Google 広告ポリシー上の注意

広告文・LP では次の表現を使っていません。今後追加する場合も避けてください。

- 「無料」（実際に無料相談を行わない限り）
- 「痛くない」「必ず噛める」など効果・結果を保証する表現
- 「No.1」「地域一番」「最先端」など比較優良・誇大表現
- 患者の体験談、治療前後の写真（限定解除要件を満たさない場合）
- 費用を強調した「〇〇円〜」のみの表示（総額の目安とリスクを併記すること）

## 5. 運用開始後のチェック（毎週）

1. **検索語句レポート**を確認し、関係のない語句を除外キーワードに追加
2. キーワード別の CPA を確認し、CPA が目標の 2 倍を超えるものは停止または入札を下げる
3. 広告の「アセットの成果」で評価が「低」の見出しを差し替える
4. 月 1 回、予約システム・電話の実来院数と広告のコンバージョン数を突き合わせる（「広告を見て来た」の受付ヒアリングも推奨）

## 7. 院内の取組との連動

2026年9月の取組事項にある「平日 13:00〜／19:30〜 の相談枠を WEB 予約で開放」は、広告の成果に直結します。

- 相談枠が WEB 予約画面で「インプラント相談」として選べることを確認してください（広告から来た人が予約メニューで迷わないように）
- 広告スケジュールでは、相談枠が埋まっている週は予算を抑え、空きがある週に強めるのが効率的です

## 8. Google 広告エディタで一括設定する手順

キャンペーン・広告グループ・キーワード・除外キーワード・広告文（4広告）を、まとめて作成できる入稿ファイルを生成できます。

1. LP の公開 URL を指定して生成する
   `python3 google-ads/build_editor_csv.py https://<LPのURL>/`
   → `google-ads/editor-import.tsv` が作られます（キャンペーンは**一時停止**状態で作成）
2. Google 広告エディタでアカウントを開き、「最近の変更を取得」
3. 「アカウント」→「インポート」→「ファイルからインポート」で `editor-import.tsv` を選択 → 内容を確認して「変更を保持」
4. 「投稿」で反映
5. 管理画面で、エディタで入れない次の項目を設定する
   - 地域：当院から半径15km ＋「所在地：ターゲット地域に所在または定期的に訪れているユーザー」
   - アセット：`assets.csv` のサイトリンク4件・コールアウト・構造化スニペット・電話番号（`{LP_URL}` を実際の URL に置換）
   - コンバージョン：「2. 配信開始前に医院で必ず行うこと」の手順
   - 広告スケジュール：6:00〜23:00、電話アセットは診療時間内のみ
6. 既存のインプラント関連キャンペーンがあれば一時停止し、新キャンペーンを有効化

### 目標値の目安

同じ運用体制の東京銀座歯科（2026年3〜5月）の実績は、月4.5〜5万円で CV 3〜4件、CPA 1.1〜1.7万円でした。たつの市は都内よりクリック単価が低いため、**月7.5万円で CV 6件以上・CPA 1.2万円以下**を最初の目標とします。
